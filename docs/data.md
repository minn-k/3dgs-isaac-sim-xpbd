# Data and redistribution policy

This source repository intentionally excludes raw scans, training images, learned 3DGS models, generated PLY files, graph NPZ files, generated splat USD files, compiled binaries, personally identifiable data, and dataset-derived screenshots.

The Wolf scene metadata is included only to document the expected OpenUSD layout. Before publishing a downloadable Wolf bundle or related screenshots, record the original dataset source, license, attribution, and preprocessing record here and confirm that redistribution is permitted.

NVIDIA Isaac Sim and Franka assets are referenced from their original installation or Omniverse source. They are not redistributed here.
